# Eventful

A full-stack event management platform for discovering, creating, and managing events with ticketing capabilities.

> **Status**: 🚧 Under Construction

## Project Structure

- **eventful-backend** - NestJS API server
- **eventful-frontend** - React + TypeScript UI

## Features (In Progress)

- Event discovery and browsing
- Event creation (Creator role)
- User authentication (JWT)
- Ticket management
- Payment processing
- Event analytics
- Role-based access control

## Tech Stack

- **Backend**: NestJS, TypeScript
- **Frontend**: React, TypeScript, Vite
- **Package Manager**: pnpm

## Getting Started

### Backend
```bash
cd eventful-backend
pnpm install
pnpm run start:dev
```

### Frontend
```bash
cd eventful-frontend
pnpm install
pnpm run dev
```
